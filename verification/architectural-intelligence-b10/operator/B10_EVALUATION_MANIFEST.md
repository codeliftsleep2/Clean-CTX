Agent: **Agent MaxHeadRoom**. No independent A/B execution is authorized by this manifest.

Ten operational questions are source-controlled under infrastructure/discovery-questions.csv,
covering ordering, serialization, language production, replay reuse, EF acquisition,

optimization, architecture knowledge lifecycle and historical verification.
All are UNRUN at preparation. Their exact CSV hash is captured before execution.

The user-owned invoke-discovery-probes.ps1 starts one ephemeral Codex CLI session
per question. Model selector is gpt-6.1-sol; a concrete backend model-version pin
and reasoning-default identity are not assumed. No conversation is supplied from
this operator session; memory injection/generation are disabled. Installed CLI
and full launch arguments are recorded by each existing wrapper manifest. The
same accepted corrected executable/profile are pinned for all probes.

Normal source-owned instructions and ordinary read-only engineering tools remain
available. The question and common read-only assessment prompt are the only task
briefing. No identities, paths, answer-key concepts, relationships or specific
queries are supplied as expected answers. Agent-selected queries, sources and
engineering dispositions must be recovered from actual transcripts.

No coaching, answer-improving retries or silent reruns are permitted. Nonzero
host exit stops subsequent sessions; preserve failures and leave unstarted probes
UNRUN. An incorrect completed answer is retained as an outcome, not retried.
Exit zero means only session completion. No automatic score is assigned.

Available views are not proven independent: ordinary read-only sandbox access is
not enforced grader/memory exclusion. These sessions are not the frozen B7
experiment and must not be graded into its results. All sixteen independent runs
remain UNRUN pending the separate feasibility/snapshot disposition.

The command may take several minutes because it runs ten actual agent sessions.
It is handed to the user, never started by the agent. It builds nothing and leaves
normal configuration and architectural sources unchanged.
