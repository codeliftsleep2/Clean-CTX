## Demonstrated limitations

Five searches returned zero units: the combined finalization phrase, serializer,
Entity Framework phrase, architecture knowledge ingestion phrase and VALIDATED
status filter. Agents recovered or explicitly disclosed uncertainty. The first
four show lexical phrasing limitations for these expressions; the last shows
lifecycle status is not executed verification. No new search implementation,
synonym authority or embedding service is justified merely by these recovered misses.

Large combined/context displays were repeatedly reported truncated. Raw event
captures retain full payloads; graph completeness is not complete model-side
inspection. Targeted acquisition/source reading recovered decisive material in
the reviewed cases. No token or response-size objective follows from this finding.

All ten answers report an initial policy-blocked shell read. No completed shell
command event appears in these captures: retain that denial as an agent report,
not invented execution evidence. Some agents obtained policies through MCP;
others disclosed they had not read them. A P03 code-discovery transport error is
actually captured. Tool failure establishes neither absence nor a graph defect.

No explicit code-context request targeted evaluator packages, current B10 operator
reports, previous B10 outputs or saved memory. This limited check does not prove
filesystem isolation or expose every host input. Evaluator exclusion was an
instruction, not enforced access denial. Historical source-owned engineering
reports were consulted as intended evidence; independent eligibility is not claimed.
