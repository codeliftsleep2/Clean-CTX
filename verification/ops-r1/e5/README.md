# E5 gated claim composition

Agent MaxHeadRoom. Rust-only written_source_observations plus angular features.
Angular owns interpretation in src/angular_meta/written_claim_composition.rs;
the TypeScript layer owns neutral selection/binding and re-exports the gated API.
No public MCP,
canonical index, persistence integration or normative contract replacement.

`claim_composition::AngularRole::acquire` performs bounded type-namespace direct
resolution for an exact const array initializer's route object. Its annotation
must resolve through the actual @angular/router public entry to Routes owned by
that physical package, with version/manifest/source witnesses. Aliased and one
namespace-qualified type imports are supported. Type declarations never become
value declarations. Local lookalikes and deeper foreign package ownership refuse
role promotion; ambient/contextual contributor closure remains explicitly open.

`Prepared::admit` separately validates the E2 observation, E4 runtime-value endpoint
and role support using the same E3 request. It retains Current/Stale/Missing/
Incompatible/Unvalidated statuses. Crossed source/hash/mapping sites are incompatible;
different root scopes cannot silently compose. Valid component evidence survives
an incompatible composition. Accessors expose existing proof and obligations.

`Prepared::classify` uses only the prepared bounded ledger. It neither acquires
nor validates. StronglySupported requires current written source, current direct
value-namespace evidence, current direct Angular role, matching scope and site,
only explicitly allowed contextual qualifications and no known relevant contributor.
Partial preserves independently established components. Unsupported preserves a
written unsupported expression; Unknown does not fabricate a requested conclusion.
JS runtime implementation, execution and canonical registration are always explicitly
NotEstablished in this increment. No numerical confidence scores are used.

Coverage defaults to Open independently of interpretation. The optional closed
mode is strictly the already scanned exact source's supported written-shape
predicate, requires current source and no producer omissions, and never certifies
Angular/workspace/runtime absence. Zero observations with Open coverage remain
NotObservedUnknownOpenCoverage. This API introduces no exhaustive query mode.
