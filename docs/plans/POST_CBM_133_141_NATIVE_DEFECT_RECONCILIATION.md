### #136: correct target, wrong operation authority

**PROVEN BY CURRENT CODE + LIVE:** handle_apply_edit checks prior read authority

attributes/decorators, not necessarily XML docs/comments. Repair must explicitly
define whole-declaration insertion, metadata ownership and overload ambiguity,

in locate.rs overwrites same-named overload slots: this is a distinct **ENTITY
IDENTITY** risk, not repaired by changing offsets.
