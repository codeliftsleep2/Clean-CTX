## Proposed complexity contracts: candidates for approval after baseline

- Complete projection: <=1 per selected consumer/kind per stable admission, already
  enforced. Legitimate per-edge comparisons against that projection may remain.
- Witness observation: report total vs distinct exact expectation per boundary;
  do not impose <=1 until observation/revalidation protocol is approved. Entry and
  commit/consumption checks may both be required.
- Structural lookup: traverse/build once per exact immutable captured authority
  and selected proof unit where equivalent; O(D+P+lookups), not arbitrary O(1).
  Duplicate/conflicting records must refuse; a map must not choose first/last.
- Index membership: target work proportional to actual participating facts and
  chosen membership structure, preserving deterministic ordering and publisher
  ownership. Hash expected-linear vs tree logarithmic tradeoff requires actual
  design, not an unreviewed new global index.
- Reconciliation: one per valid stable batch or affected dependency set only when
  public visibility and full stale retirement are preserved. An individual public
  mutation may still need immediate reconciliation; no batch inferred across calls.
- Query: unchanged requests may need currentness observations but must not perform
  unnecessary recompile/discovery/catalog construction. Existing generation-aware
  invalidation remains authoritative.
- Lock scope: prove revision/ownership and race refusal first. No lock-time budget
  from flaky elapsed thresholds; deterministic lock-held work and interleavings.
