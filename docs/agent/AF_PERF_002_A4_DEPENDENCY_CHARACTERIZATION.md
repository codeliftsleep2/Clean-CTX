## Default caller graph and ownership

Dirty exact-call workspace_query -> prepare current C# generation -> reconciliation
-> dependencies::footprints(state, artifacts). Partition grouping is local to that
reconciliation. Each partition clones its resolution units once, collects owner
files and calls ancestry_obligations_for_files once. That helper already builds
ONE source-symbol index for all supplied owner files. Do not describe it as a
fresh full index per owner or propose new sharing to repair a nonexistent defect.

For each owner, collect_obligations scans class inputs to select seed identities,
visits their complete declaration families using the existing index, scans the
inputs again to recover matching source inputs and follows resolved admitted-source
ancestry. An additional short-circuit class search locates the base declaration's
original scope. Attributes/aliases also contribute obligations and hints. Cycle,
ambiguity, unsupported and unresolved behavior is preserved; counts are not proof
that every traversal can be removed. Partial/duplicate declaration families must
remain complete even if only one current owner appears interesting.

Back in footprints, each owner's obligations filter every partition peer. Self is
excluded; exact required owners short-circuit before discovery-term matching.
Otherwise existing ordered discovery terms test the immutable source snapshot
using contains. Matching emits path/hash dependencies, not semantic role authority.
Text hints deliberately preserve conservative dependencies that may later revoke
truth or reveal ambiguity. A text match need not be a resolved semantic reference.

Separate successful compress_code_context C# -> dependencies::current_parts:
capture PublicationStamp, select retained partition peers, resolve classes/project
edges, call SINGLE-owner footprint and append existing artifact dependencies.
That helper independently selects peers/clones units and builds its own obligation
index. Current generation stamp and every dependency hash must still validate
before returning projected IR/edges/dependencies/hash. This operation MUST NOT reuse
reconciliation's transient selection/index state as a silent optimization.

Both paths ultimately publish independent live/index/retained owners through their
existing boundaries. No new generation cache, authority registry, owner map,
normalization, partition semantics or currentness shortcut is introduced.
