## Proposed bounded contract

Extend the existing native source-owned payload with demanded constructor
parameter evidence. Angular continues to own DI interpretation; TypeScript owns
parameter/declaration/reference identity and type/value binding eligibility.

1. Retain the exact declaring class ID, constructor/parameter/annotation spans,
   annotation shape and independently interpreted type and runtime-value
   resolutions, including truthful ambiguity/unavailable/unsupported outcomes.
   Acquire through the existing authorized immutable Host and actual project.
2. A runtime class-token claim requires compatible exact type/value endpoints
   and runtime import eligibility. A type-only import or interface must not gain
   a runtime endpoint merely because its type lookup succeeds. Keep generic and
   lexical shadows distinct. Preserve required merge contributors where relevant.
3. Retain only demanded typed facets and witnesses in the existing payload;
   do not retain whole sources or introduce a new inventory/cache/owner/registry.
   Old payloads lacking facets must reacquire before serving migrated authority.
   Advance existing producer compatibility for changed serialized meaning.
4. Migrate constructor and field joins to the same owner/token fact identity.
   Repeated uses of the same token share a fact; same-named distinct declaration
   owners remain distinct. Do not change EntityRef equality or public schemas.
5. Preserve established noncanonical symbolic constructor behavior separately
   from canonical proof. Never manufacture a declaration for absent names or use
   a failed lookup as permission for written-name fallback. Explicitly classify
   each existing constructor form before replacing its path.
6. Parameter decorators, explicit token overrides, qualified types and other
   established requirements remain in scope. This proposal does not redefine
   @Inject precedence, primitive/generic semantics or diagnostic parity. Trace
   those required forms and preserve their contracts; do not silently narrow
   support to the initial class-alias fixtures or claim full DI migration.
