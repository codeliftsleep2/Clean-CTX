## Canonical question and proposed exit

For a real named const with native ApplicationConfig annotation initialized by
an exact native mergeApplicationConfig call, which named configs are explicitly
written as its arguments, and does a native bootstrap call reference that exact
result declaration?

This is the next W06/AQ14 structural question after accepted named-bootstrap
references and direct-inline provider membership. It does not answer which
providers are effective, how arbitrary values merge, or which application runs.

Proposed example:

```ts
const appConfig: ApplicationConfig = mergeApplicationConfig(baseConfig, featureConfig);
bootstrapApplication(Root, appConfig);
```

The exact result variable is a real declaration. It must not be replaced by an
API declaration, a fictitious object declaration, or either argument declaration.
