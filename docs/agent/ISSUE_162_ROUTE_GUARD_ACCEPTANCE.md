## Approved contract

For an exact admitted native typed-const Routes object, GuardedBy records the
resolved runtime declarations explicitly written in its ordinary canActivate Array.
Guard is a use classification, including functions, typed values, classes and
noncallable values. It does not establish execution, signature validity, inherited
applicability, active routing or provider/injector scope.

One relation represents one RouteOccurrence/DeclarationId pair. Repeated slots
remain independent neutral support; distinct objects survive equal display labels.
Unique field mapping, exact Array/slot/reference joins and source/hash witnesses
are required. Valid ordinary slots survive unproved siblings. Duplicate fields
refuse; unsupported slots are never evaluated. Container/object structure must
itself be admitted. There is no weak fallback for the owned canActivate branch.
Other guard kinds survive independently; outside-envelope behavior stays legacy.
