## Distinctions that must survive

1. A config declaration can exist without any bootstrap call.
2. A written bootstrap call can be conditional or never run. Do not rename a
   static reference fact into actual activation or runtime application identity.
3. Two call sites may reference the same root and config; neither call-site nor
   configuration identity may collapse by display name or endpoint equality.
4. A valid Component and a valid config elsewhere do not prove argument membership.
5. Provider composition and config-object composition are different questions.
   The approved provider-array walker must not evaluate mergeApplicationConfig.
6. TestBed summaries are not a bootstrap/application carrier: testing.rs currently
   extracts textual summaries and separate Tests edges, with independent W10 scope.
