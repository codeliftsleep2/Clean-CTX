## Acceptance and limitations

These are design candidates, not twelve installed mandatory gates. The existing
AF-PERF obligations remain mandatory. Do not use an AFF identifier as evidence a
property is proven, or a GARC entry as permission to skip existing regressions.
Every implementation proposal must name owner authority revision, legitimate work,
tracked negative witness, actual production consumer and enforcement cost.

Historical mutation proves a test detects a defect only when the defective source,
same witness and failure reason are attributable. A current PASS alone is not
prevention evidence. No empirical acceptance requirement is retired by deterministic
counter GREEN. Static AST scope is not a whole-program cost oracle.
