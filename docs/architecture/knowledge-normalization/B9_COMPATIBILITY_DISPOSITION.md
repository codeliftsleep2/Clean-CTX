# B9 compatibility disposition

Agent: **Agent MaxHeadRoom**. Additive production interface, shared lifecycle owner.

`pcg_knowledge_v1` is first class and the normal documented architectural workflow.
It is advertised and dispatched whenever the existing document profile is enabled.
It uses the same session, scan, validation, database transaction and currentness
owner. Agent instructions in AGENTS.md, pcg-authoring.md and tooling.md route to it.
The local ignored engineering projection is aligned. No extra host plugin or server
is required by the provider. This session does not advertise the conditional tool;
actual stdio reachability does not establish host deployment or general adoption.

`pcg_documents_v1` retains legacy whole-document search, get, related, context and
history semantics, default/explicit inline and explicit context-only source references.
Its legacy declaration JSON shape excludes the new source-selector extension, so
existing consumers do not receive an unexpected metadata schema. Exact historical
revision hashing remains based on source/declaration/evidence as before. New markers
and source declarations legitimately advance observed source revisions; old source
bytes/revisions are retained. There is no claim of byte equality across different
source revisions. Same-source legacy format reconstruction remains exact.

Schema v2 requires the new executable. Existing v1 catalogs migrate atomically and
old executables refuse v2 explicitly. No destructive downgrade is provided. Request
token hints remain retired in the legacy API and do not exist in the knowledge API.
Separate enrolled evidence, code context, proxy, semantic queries and runtime IR
behavior are unchanged. This is not C15 CI alignment, M4b approval or host integration.

The governing contract documents both interfaces and their transition. Knowledge
completeness is declared-unit/operation completeness, never inferred applicability.
Original supporting artifacts remain exact, current, hash-pinned source acquisitions.
No evidence tier silently weakens the declared evidence associations.
