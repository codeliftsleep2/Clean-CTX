## Finding and proposed disposition

Clean-CTX already has a declared authority spine, independently meaningful
invariants, detailed subsystem contracts and extensive negative evidence. The
normalization problem is principally separating propositions and their lifecycles,
not discovering a new taxonomy. Blanket Markdown admission would confuse guides,
old plans, experiments, live definitions and current authority. Blanket admission
of historical reports would also connect large source payloads to otherwise narrow
questions: PCG context returns complete documents, not just declaration sections.

Proceed with the dependency-aware batches below. Preserve original investigations,
source identities and failed outcomes. First admit small controlling authorities;
then split mixed current contracts, reconcile conflicting dispositions, and finally
attach narrowly selected historical evidence. This report proposes the structure;
it does not authorize or execute the subsequent migration.

## Identity and metadata policy proposed for migration

Use the implementation's GLS identity grammar unchanged. `AUTH.<UPPER_SNAKE>`
names a new controlling contract; `INV.<UPPER_SNAKE>` aliases an invariant only
when its existing identity is incompatible with the grammar;
`DEBT.<UPPER_SNAKE>` is available only for an explicit debt proposition. Existing
compatible declarations keep their IDs. The actual baseline declaration
`PCG-175-ADOPTION` remains unchanged. DOC-042/068/081 examples and controlled
scenario identities are not reserved production authority IDs.

Existing compatible identities such as WIRE-001 remain graph identities as well
as source identities. The mapping in invariants.md retains them verbatim and
introduces aliases only for incompatible identities. `C-22` cannot be
used as-is under this parser; `INV.C22` retains its historical source name.
`DIS-2026-039` similarly needs an explicit compatible alias, not silent renaming.
ADR-001 maps to `ADR-001` for its exact owner-aware call-inspection proposition;
reuse elsewhere requires checking for another actual ADR-001 declaration first.

DOC allocations in inventory.csv are opaque planning reservations assigned to
source-backed findings, not IDs calculated from a filename. Persist the mapping;
never renumber on sorting, move, or extraction. A mixed source-record reservation
is held, not an umbrella authority. Focused IDs in nodes.md replace that reservation
when it would duplicate a proposition. Historical records retain original path,
section, baseline commit and source hash even when moved. Semantic replacement
gets a new identity and an evidence-backed SUPERSEDES relation; a rename alone
retains identity and becomes a source revision.

No inventory classification becomes a new kind/status. Exact kinds, statuses and
directions remain those in PCG_175_SOURCE_DOCUMENT_GRAPH.md. Candidate rows use
only those values. Proposed FROZEN means a suggested standing contract snapshot
to be ratified during migration, not a newly discovered owner approval. Conservative
RESEARCH/INVESTIGATING source records preserve actual reported results in prose;
they do not erase negative evidence or promote a report to VALIDATED. Use more
specific statuses only after the exact subject and source disposition agree.
No RECLOSES or BANKS relationship is established by this assessment.

These are content batches, not a new status/transition model. Whole-candidate
validation means both endpoints must exist together: a newly introduced
SUPERSEDED target and its exactly one SUPERSEDES successor are an atomic pair.
An evidence-backed BLOCKED node needs its explicit unresolved blocker; only
RECLOSED/BANKED satisfies blockers under the current GLS rules. Ordinary
IMPLEMENTED evidence must not be promoted just to satisfy a blocker. General
cycles are representable but do not prove truth. Hold unsupported blocker or
supersession claims instead of fabricating endpoints.

For each batch, author declarations in actual source Markdown, inspect the
complete candidate graph through the existing tool, correct source diagnostics,
retrieve relevant context and retain generations/revisions/edges. Compare changes
to controlling endpoints, successors and falsifiers; do not restart discovery for
an unrelated generation change. Review full returned source sizes against owner
limits. No partial context or keyword-selected subset establishes closure.
