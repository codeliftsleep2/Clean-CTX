## [0.6.4] - 2026-09-14

### Added

* **All-feature development Cargo policy** — repository-development builds, checks, tests, Clippy runs, and examples now default to `--all-features`; Cargo's package defaults remain the release-default product configuration. Intentional feature-restricted runs must be identified explicitly and cannot be reported as all-feature verification. This policy does not authorize agents to cross the existing long-running-command boundary. (`.clinerules/engineering.md`, `AGENTS.md`, `docs/agent/verification.md`, `docs/agent/tooling.md`)
* **MSTest + Moq .NET testing meta-layer** — `[TestClass]`, `[TestMethod]`, `[DataTestMethod]`/`[DataRow]`, `Mock<T>`, Moq setup/verification behavior, and test fixtures now produce fidelity-gated testing metadata. Conservative naming/construction inference emits `TestClass --Tests--> Class` semantic edges through the production meta pipeline, with an isolated configuration switch for opt-out. (`src/dotnet_meta/testing.rs`, `src/dotnet_meta/marker_builders.rs`, `src/layers/meta/semantic.rs`, `src/config_meta_layers.rs`)
* **Angular TestBed + Vitest testing meta-layer** — Angular `.spec.ts`, `describe`/`it`, `TestBed`, `vi.fn`, and `vi.spyOn` source shapes now emit fidelity-gated `Φdescribe`, `Φit`, `ΦtestBed`, and `Φspy` metadata independently of Angular decorators. Conservative agreement between `createComponent(...)` evidence and spec filenames emits `TestArtifact --Tests--> Component` semantic edges; conflicting evidence fails closed. (`src/angular_meta/testing.rs`, `src/angular_meta/phi.rs`, `src/layers/meta/mod.rs`, `src/layers/meta/semantic.rs`)
* **Angular Reactive Forms meta-layer** — statically recognizable `FormBuilder`, `FormGroup`, `FormControl`, and `FormArray` construction now emits fidelity-gated `Φform`, `Φcontrol`, `Φarray`, and `Φvalidator` metadata. Constructor/injected builder aliases, nested arrays, built-in/custom validators, formatting variants, configuration isolation, and production dispatch are covered without duplicating template bindings. (`src/angular_meta/reactive_forms.rs`, `src/angular_meta/reactive_forms_imports.rs`, `src/angular_meta/reactive_forms_validators.rs`)
* **ngx-formly Angular meta-layer** — statically declared `FormlyFieldConfig` arrays now emit fidelity-gated field, group, and controlled-expression metadata while preserving hierarchy and source order. Dynamic keys/types and template-copy text are not fabricated; Formly and Reactive Forms metadata can coexist and the layer has its own isolated configuration switch. (`src/angular_meta/formly.rs`, `src/angular_meta/phi.rs`, `src/layers/meta/mod.rs`)

### Fixed

* **`apply_edit delete` whole-declaration boundaries** — delete previously reused the resolved unit's brace-delimited body span, leaving method signatures and leading metadata behind for the syntax gate to reject. Delete-containing batches now map the unchanged body span to its enclosing declaration capture and include contiguous attributes, annotations, and decorators in the removal range. `replace_body` remains body-scoped; stale-text validation remains mandatory and body-based; IR/wire span contracts and batching semantics are unchanged. Cross-language regressions cover C#, TypeScript, Java, and Rust first/middle/final members, leading metadata, closing-delimiter adjacency with and without blank lines, `replace_body`, and batched deletion. (`src/edit/locate.rs`, `src/edit/apply.rs`, `src/mcp/tool_handlers/edit.rs`, `src/tests/edit/delete.rs`)
* **Vitest multiline object-spy identity** — spies declared through multiline or formatter-wrapped object literals and fluent `vi.fn()` chains now use the containing assignment marker consistently with single-line equivalents. Direct assignments remain unchanged, mixed `vi.fn`/`vi.spyOn` output stays sorted, and ordinary object properties are not misclassified as spies. (`src/angular_meta/testing.rs`, `src/tests/angular_meta/testing.rs`)
* **Typed and untyped Reactive Forms import parity** — `UntypedFormBuilder`, `UntypedFormGroup`, `UntypedFormControl`, and `UntypedFormArray`, including aliased and mixed imports, now activate and render the same metadata as their typed counterparts without duplicate discovery. (`src/angular_meta/reactive_forms_imports.rs`, `src/tests/angular_meta/reactive_forms.rs`)
* **Reactive Forms reconstruction and nested-group preservation** — repeated construction of the same form, control, or array now merges compatible structural evidence in stable source order instead of emitting duplicate logical artifacts. Nested `FormGroup` fields retain recursive group/control/array structure, reuse the existing `Φform` vocabulary at High fidelity, preserve descendant validators, and remain compact without false control markers at lower fidelities. (`src/angular_meta/reactive_forms.rs`, `src/angular_meta/reactive_forms_normalize.rs`, `src/tests/angular_meta/reactive_forms_structure.rs`)
* **Typed declaration-name extraction** — the shared declaration helper no longer mistakes the final identifier in a TypeScript type annotation for the declared field. `confirmForm: UntypedFormGroup = ...`, generic/union annotations, local declarations, modifiers, definite assignment, typed injected builders, and typed Signals now resolve the syntactic target while preserving simple/member assignments, optional names, colon-only properties, and invalid-expression rejection. The oversized shared utility was decomposed into scanner, class-source, and declaration modules without changing its public re-export surface. (`src/meta_util.rs`, `src/meta_util/declaration.rs`, `src/meta_util/scanner.rs`, `src/meta_util/class_source.rs`, `src/angular_meta/signals.rs`)

### Tests

* **Live CBM E2E lifecycle stabilization** — live tests now share at most one healthy process-scoped `McpState`/`GraphBridge`/CBM subprocess, replace degraded instances before launching successors, use the shared configured multi-root fixture, restore workspace state during normal and panic unwinding, and avoid assertions while holding the bridge mutex. The oversized E2E suite was split along scenario boundaries; DIS-2026-012 records the lifecycle finding and verified grouped scenario. (`src/tests/cbm/e2e.rs`, `src/tests/cbm/e2e_basic.rs`, `src/tests/cbm/e2e_live_queries.rs`, `src/tests/cbm/e2e_multiroot.rs`, `src/tests/cbm/e2e_reindex.rs`, `docs/agent/DISCOVERY_REGISTRY.md`)
