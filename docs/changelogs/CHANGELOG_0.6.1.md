## [0.6.1] - 2026-09-04

### Added

#### Workspace/semantic architecture completion

* **SemanticEdge production lifecycle wiring into `WorkspaceIndex` (Phases A/B)** — semantic edges extracted during compilation now reach the workspace index through the production `provide_code_context` path, including the token-economics fallback branch (edges are preserved even when rendering is skipped in favor of `raw_passthrough`). (`src/ir/compiler.rs`, `src/mcp/state.rs`, `src/mcp/tool_handlers/core.rs`, `src/mcp/tool_helpers.rs`, `src/workspace/index.rs`)
* **`workspace_query` MCP tool** — read-only cross-file semantic query API over `WorkspaceIndex` supporting `find_entities`, `forward_edges`, `reverse_edges`, `entities_in_file`, `transitive_dependencies`, and `has_cycle`, using the `(domain, entity_type, name)` identity model. No changes to the write lifecycle, CBM module, or WorkspaceIndex internals. (`src/mcp/tool_handlers/query.rs`, `src/mcp/tool_handlers/registry.rs`, `src/mcp/tools.rs`)
* **Canonical MCP response contract and `outputSchema`** — `workspace_query` responses conform to the canonical `CallToolResult` envelope (`content` + `structuredContent`) and declare `outputSchema` in `tools/list`, matching the 0.5.0/0.6.0 structured-output convention. (`src/mcp/tool_handlers/query.rs`, `src/mcp/tools.rs`)
* **`BuiltinMetaLayer` entity projection** — non-framework source files now project their declarations as `builtin`-domain entities, so ordinary compiled files contribute real entity occurrences to `WorkspaceIndex` queries. (`src/layers/meta/builtin.rs`)
* **WorkspaceIndex entity-occurrence deduplication** — repeated edge participation no longer multiplies entity occurrences per file; each `(identity, file)` occurrence is registered exactly once. (`src/workspace/index.rs`)

### Fixed

* **IR CTOR identity preservation (DIS-2026-002 / IRPAT-001)** — consumptive CTOR/EMPTY_CTOR pattern compression must not consume a `DefMethod(M)` while a surviving M-referencing operation (`DataFlow`, `SideEffect`, `ExecutionContext`, `ControlFlow`) would be orphaned. The pattern recognizer now declines compression for such regions, preserving the fully valid annotated instruction stream. (`src/ir/patterns.rs`)
* **IR Edit-fidelity Body/Flags orphaning (DIS-2026-003)** — an Edit-fidelity `Body(M, ...)` operation between a constructor's `Return(M)` and its trailing `Flags(M, ["PRIVATE"])` (generated by a parameter property) is now treated as an unrepresentable M-reference. Compression declines rather than consuming `DefMethod(M)` and orphaning the detached `Flags(M)` (previously `[E003] FLAGS references unknown method`). (`src/ir/patterns.rs`)
* **NgRx `Selects` semantic names** — `select('panelState')` surfaces the literal value `panelState`, not the raw quoted source slice `'panelState'`. (`src/angular_meta/ngrx.rs`)
* **NgRx `Dispatches` action names** — `dispatch({ type: TOGGLE_PANEL })` surfaces the `TOGGLE_PANEL` action identifier, not the opening object-literal brace; `dispatch(actionCreator())` continues to surface the action name. (`src/angular_meta/ngrx.rs`)
* **Decorated builtin class names** — `@Component(...)` / `@Decorator(...)`-prefixed TypeScript declarations register their real class name (never the decorator head); the builtin layer locates the declaration keyword generically instead of assuming the header starts at byte 0. (`src/layers/meta/builtin.rs`)
* **Literal `HasSelector` representation** — the `HasSelector` semantic-edge object name is now the exact declared selector string (e.g. `app-widget`, `[app-widget]`, `.app-widget`) rather than an artificially bracketed marker; the selector forms remain distinct semantic identities. (`src/angular_meta/semantic.rs`)

### Changed

* **`resolve_selector()` literal lookup** — selector resolution now looks up the literal selector string stored by the `HasSelector` edge; no lookup-key encoding is reconstructed at query time. (`src/workspace/index.rs`)
* **Constituent invariants established** — the Selector-Value Invariant (a `HasSelector` object name MUST be the exact declared selector string, without encoding, wrapping, or normalization) and the Index-Encoding Invariant (internal lookup-key encoding MUST NOT leak into semantic entity identity) are now represented in `docs/ARCHITECTURAL_INVARIANTS.md`. (`src/angular_meta/semantic.rs`, `src/workspace/index.rs`)
